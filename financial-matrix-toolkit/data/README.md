# Data directory

`prices_cache.csv` is the committed daily-close price matrix the toolkit loads
by default (15 large-cap US equities, see `data.py::TICKERS`).

## Is this real or synthetic?

In an environment with open network access, run:

```bash
python main.py --refresh
```

This fetches **real** daily closes via `yfinance` and overwrites the cache.

In this repository the committed cache was generated by the **seeded synthetic
generator** (`data.generate_synthetic_prices`, seed 42) because the build
environment's egress policy blocks every public market-data host (Yahoo, Stooq,
Binance, AlphaVantage, Tiingo, Nasdaq, FMP all return 403). The synthetic series
is built to mimic real equity markets:

* a dominant market factor + sector blocks (so PCA/RMT find real structure),
* volatility clustering via an AR(1) log-vol process (so EWMA beats the null),
* a calm/crisis regime (so the HMM and the correlation change-detector work),
* near-zero predictable drift and unpredictable signs (so the Tier-D direction
  models correctly fail to beat the coin flip).

The loader resolution order is always: **live yfinance → cached CSV → synthetic**.
Delete this CSV (or pass `--refresh`) on a networked machine to use real data.
